## Project 5CHAN - A 4CHAN family friendly clone

### Project Overview
This project is a web application that mimics the functionality of 4CHAN while ensuring a family-friendly environment and only related to cats and gardens. It allows users to create and browse imageboards with strict content moderation to prevent inappropriate material.

### Installation and Run Instructions
1. **Clone the repository**
2. ```npm i && npm run dev``` in backend and ```npm i && npm run start``` in frontend
3. Access the application at `http://localhost:3000`

### Justification of technical choices
1. **Framework**: Chose React and ExpressJS for their flexibility and simplicity.
2. **Frontend**: Used Antdesign for a modern and responsive UI.
3. **Database**: Selected JSON files for simplicity in data storage and retrieval.
4. **Content Moderation**: Implemented strict filtering to ensure all content is family-friendly.
