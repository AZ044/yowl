## Note form discussions with classmates
### Needs:

**Modern User Experience**

Users need an interface that functions in 2026, not 2005. This includes responsive design, intuitive navigation, and mobile optimization without sacrificing the imageboard format.

**Conversation Coherence**

Better reply threading, conversation visualization, and optional temporary IDs within threads help users follow complex discussions without compromising anonymity.

**Enhanced Media Handling**

Creative users need better support for visual content: larger image displays, gallery views, higher file size limits, and support for multiple media formats (GIFs, short videos).

### Frustration:

**Limited Media Capabilities**

Small image thumbnails, restrictive file size limits, and poor gallery functionality frustrate users who engage with visual content.

**Overwhelming Toxicity & Lack of Moderation**

While users appreciate freedom of expression, the complete absence of moderation creates environments full of spam, harassment, and illegal content that make boards unusable.

**Difficulty Following Discussions**
Poor reply visualization and thread structures make it hard to follow multi-person conversations or understand argument flow.

### Habit or expectation:

**Content Consumption**

- Users browse multiple boards based on interests (creative, discussion, technical)
- They seek both entertainment and serious discourse
- Visual content is scanned quickly; text discussions require deeper engagement

**Users often revisit threads multiple times before they expire Posting Behavior**

- Anonymous posting reduces posting anxiety
- Users contribute when they have substantial input or need feedback
- Creative users post work for honest critique
- Discussion-oriented users engage in philosophical or intellectual debates
