## This prototype supports the following interactions:
- **Accessing boards**: Users can navigate through different boards using a menu.
- **Accessing threads**: User can click on threads to view messages
- **Posting**: Users can create new threads/posts with a simple form that includes fields for title, description, and image upload.
- **Interacting with posts**: Users can reply to posts using clearly visible buttons.
