## Essentials screens
- Home: The main page with with different purpose:
    1. Choose boards
    2. Login
    3. Sign up

- Board: The page when different thread is created around the main theme of board

- Thread: The environement when the content is posted 

- Post: Individual unit content within Thread. The post is interactive for another user:
    1. Like/Dislike
    2. Reply
    3. Report

## Minimal features
- Create thread
- Post
- Login/Signup

## What is explicitly excluded
- Customization profile: avatar, change name, ...
- Direct message (DM)
- Following
