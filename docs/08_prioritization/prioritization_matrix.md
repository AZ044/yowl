Priority 1:
- User can navigate through different boards using a menu.
- User can click on threads to view messages.
- User can create new threads/posts with a simple form that includes fields for title, description, and image upload.
- User can reply to posts using clearly visible buttons.
- Login and registration functionality.

Priority 2:
- User can edit or delete their own posts.
- Likes or upvotes on posts.
- Report inappropriate content.

Priority 3:
- Search functionality to find specific threads or posts.
- Avatar customization for users.
- Notification system for replies or mentions.
- Dark mode option for better accessibility.
